# svg-editor-cli

Lab1 Phase 1 —— 命令行 SVG 编辑器（TypeScript，面向对象，Command 模式）。

```bash
npm install
npm run cli                      # 进入 svg> 交互式 REPL
npm run cli < examples/demo.txt  # 把命令脚本回放成 transcript
npm run check                    # 类型检查 + 依赖规则 + 全部测试
```
